Игра и GitHub-репозиторий ещё не созданы. Баланс, стек и графика — проекты решений.

Артур предоставил приватный kotlyakov/barista. Созданы 21 Issues, исправлены инструкции и снят прежний блокер доступа.

## ТЗ v0.2 — 2026-10-28
Предъявлена полная спецификация: операции, формулы, рецепты, клиенты, сутки, магазин, короткие забеги и приёмка. Рекомендации не приняты за утверждения.

## ТЗ v0.3 — 2026-10-28
Артур одобрил ТЗ с правками: все этапы влияют на качество, дефекты вкуса считаются отдельно; настроение героев сохраняется.

## 2026-10-29 — нативное техническое ядро
- Godot 4.5.1: приготовление/качество, выдача/оплата, надёжные сохранения, профили, смена, тренировка, магазин, ежедневные условия/усиления.
- 15 headless сценариев, Linux debug export. Два дефекта сохранений из независимого ревью исправлены.
- Утверждённый внешний вид 09 сохранён как источник; нативный UI технический. Android export ожидает принятия SDK license; финальная игра не готова.

## 2026-10-29 — Android technical preview 0.1.0
- Android SDK license принята по явному ответу владельца, SDK настроен.
- Собран и сохранён ARM64 APK (27 МБ), v2/v3 подпись/ZIP/16 KB alignment/manifest PASS, 15 тестов PASS.
- Исправлены настройки Android export и добавлены повторяемый build script и APK checker.
- Android runtime NOT_RUN: программный эмулятор без KVM не загрузился за 180 с. Это техническая сборка с заглушками, не окончательная игра.

## 30.10.2026 — нативная единая кофейня
Утверждённая графика 09, вступление 3 секунды/пропуск, деньги/день, меню-пауза, сохранённый mute, прогресс на стойке без людей. Старые настройки мигрируют без сброса; тренировка и подтверждённое восстановление профиля сохранены. Кандидат звука синтезируется без внешних файлов. Новый APK в этой среде ещё не собран.

## 0.3.0 — 30.10.2026
Новый ARM64 Android preview с единой кофейней, вступлением, меню/паузой/mute, прогрессом и утверждённой графикой09. CI экспорт восстановлен, подпись совместима с0.1.0, данные не сбрасываются кодом при миграции. APK29,9MB сохранён. Физический Android/Pixel и окончательное аудио не проверены.
