# Путь бариста — пакет разработки для ИИ-агентов
Версия пакета 1.0 • 27.10.2026 • Владелец продукта: Артур.
Рабочее название, не утверждённый бренд. Это документация и задания, не готовая игра.

## Начать здесь
1. Распаковать архив в корень нового репозитория. Сохранить структуру каталогов.
2. Передать агенту текст из START_HERE.md. Любая модель сначала читает AGENTS.md.
3. Координатор сверяет state/PROJECT_STATE.json, задачи и историю Git; выполняет TASK-001.
4. Использовать существующий приватный GitHub kotlyakov/barista по docs/GITHUB.md. Не загружать пакет в чужой игровой проект.
5. После подготовки решений получить утверждение ТЗ и отдельно макетов и звука. До этого допустимы документация и материалы для выбора, но не финальная реализация игры.

## Где что искать
- AGENTS.md — обязательные правила для всех агентов.
- docs/REQUIREMENTS.md — исходные требования Артура и их идентификаторы.
- docs/GAME_SPEC.md — рабочий проект ТЗ; утверждённые требования отделены от предложений.
- docs/ROADMAP.md — этапы и условия перехода.
- tasks/TASKS.json — единственный реестр задач и их статусов.
- state/PROJECT_STATE.json — текущий этап, следующее действие и препятствия.
- docs/DECISIONS.md — журнал решений и открытых вопросов.
- approvals/REGISTRY.json — единственный реестр утверждений графики, звука и ТЗ.
- docs/AGENT_WORKFLOW.md, agents/ — роли, делегирование и передача работы.
- docs/GITHUB.md — создание и ведение репозитория.
- docs/TEST_PLAN.md — проверки игры и критерии выпуска.
- config/BALANCE_DRAFT.json — стартовые гипотезы баланса, не утверждённые числа.
- templates/ — формы задачи, передачи, решения, утверждения и отчёта об ошибке.

## Проверка пакета
Из корня: `python3 tools/validate_project.py`.
Проверка контролирует структуру, ссылки задач, зависимости, блокировки и реестр утверждений.
Она не доказывает качество игры, достоверность одобрения пользователя или успешную сборку APK.
