# Восстановленная кофейня 09 с новым потоком запуска

Текущие исходники веб-макета после указания Артура 30.10.2026. Каноническая опубликованная копия: Site appgprj_6ae1b4d1e3bc8191b569fb298107c732, source commit 80acedc5d8bd1e9b947a6cac7574a5f27050a983. Доступ Site не изменялся.

Запуск для разработки: из этого каталога `python3 -m http.server 8000`, затем `/dist/`. Проверки: `node check-shell.mjs`, `node check.mjs`, `node check-save.mjs`, `node check-actors.mjs`. Не запускать старый review-v1 вместо этой сцены.

Активный фон `dist/assets/cafe-animation-room.png` побайтно совпадает с утверждённым VISUAL-002/v9. Подвижные персонажи используют прежний SVG-риг. Добавлены только оболочка intro/play/menu/progress, HUD, звук и улучшения. Исходные immutable материалы v9 отдельно восстановлены в approvals/materials/VISUAL-002/v9/ с проверенными SHA-256.

Новый вход длится 3 секунды, тап пропускает. Меню и прогресс ставят игру на паузу; прогресс скрывает все человеческие фигуры. Улучшения/кошелёк/звук и прежние заказы сохраняются. Процедурная музыка и эффекты — кандидаты для прослушивания. На первом автоматическом запуске звук ждёт пользовательского жеста по правилам браузера.

Это интерактивный веб-макет, не нативная игровая сборка. В нём ещё два временных гостя и несколько стаканов, в отличие от основного Godot-ТЗ. Старые ссылки/панель тестирования в HTML скрыты и не входят в пользовательский поток. Реальные браузерные клики в текущем сеансе NOT_RUN; проверки модели и сохранений PASS.
