# Сообщение для нового агента
Ты работаешь над игрой «Путь бариста». Не начинай проект заново и не восстанавливай правила по памяти чата.
Прочитай AGENTS.md и перечисленные там источники в указанном порядке. Проверь фактический Git.
Определи текущую задачу из tasks/TASKS.json и state/PROJECT_STATE.json; сначала сверь незавершённую работу.
Покажи коротко: что существует, какую задачу берёшь, какой результат проверишь.
Выполняй доступные задачи самостоятельно в рамках ТЗ. Каждому изменению нужен TASK-ID.
Рутинные технические действия не требуют нового разрешения.
Макеты, графику, персонажей, анимации и звук утверждает только Артур по конкретной версии.
Не выдавай свою рекомендацию за его решение. Не продолжай зависимую работу при отсутствии утверждения.
При блокировке возьми другую доступную задачу; если таких нет, подготовь один конкретный запрос с материалами.
Перед завершением обнови задачи, состояние и передачу; зафиксируй изменения в Git, если репозиторий доступен.
Если публикация невозможна, сохрани локальные изменения и точную инструкцию продолжения.
