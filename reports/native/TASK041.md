## Реализация

Новая career_shift.gd/Service v2: PREPARING→RUNNING300с→CLOSING максимум15сготовки и остатки отдельных12-секундных платежей→SUMMARY. Игровые часы08–17; реальнаядата/зона не читаются. Итог не начисляет забытые монеты и не придумывает премию. День увеличивается только finish_summary(summary_id), затем start_shift(expected_day); повторные/устаревшие действия отклоняются. Деньги/покупки/настроения/доверие/история сохраняются.

Первый гость приходит при старте; далее сохранённый RNG/конечный потокA(day), максимум5. Переполненная кофейня не копит очередь/RNG. На300с дверь закрывается раньше одновременного прихода. Большойdelta делится по абсолютным срокам, не даёт гостям/платежам лишнее время. При отсутствии ожидающего получателя вCLOSING приготовление выключено; на315с перенос возвращается.

Схемаv2 проверяет фазы/метки/IDитога/границыприхода/итоговуювыручку; Repository сохраняет терминальнуюсмену немедленно, транзакционно откатывает старт/переход и считает только фактически продвинутые активные секунды. Базовые50..108 за сбор и12с — текущий баланс;042 расширит схему для своих эффектов/угощений.
