# Независимое ревью технического ядра

Ревьюер native_review, отдельный контекст, read-only. Просмотрен весь диапазон локального импорта ac27c54..aa6a9a2: код, ТЗ v0.3 и 13 исходных Godot-сценариев. Вердикт: два Important исправить до merge; один Minor отложить. Это ревью технического ядра, не финальная приёмка игры.

| Найдено | Исправление и доказательство |
|---|---|
| Фоновый checkpoint при двух повреждённых снимках сохранял пустую Session | ready=false запрещает checkpoint; только явный сброс открывает запись. recovery_regression_test.gd RED → GREEN, повреждённые байты не меняются, повторный запуск не сбрасывает карьеру. |
| Перезапуск тренировки стирал основную карьеру | В training restart создаёт только тренировочную Session, main остаётся прежней. training_reset_test.gd RED → GREEN, сохраняются деньги/оборудование/профили и снимок на диске. |
| Minor: противоречивые mode/reward_collected проходят базовую валидацию | NAT-009. Нормальные переходы не создают такой снимок; до выпуска добавить строгое отклонение/резерв. |

Дополнительное наблюдение fix pass: JSON восстанавливает числа как float. Счётчики/кошелёк/ID/уровни/тапы нормализованы в int на границе restore; после этого вся серия **15/15 PASS**. Linux Debug повторно экспортирован и headless запущен. Код и тесты опубликованы commit **841bdc7393f72380b57d4df118d420a536344c94**.

Не оценивались как готовые: финальный визуал/звук, Android touch/performance, баланс/калибровка и DST. Они явно открыты и не закрываются этим ревью. Таймаут оплаты 12 секунд сверялся с более новым указанием владельца, а не с исторической бессрочной оплатой в ТЗ.

Решения исполнителя, которые должен видеть следующий агент:
- Правила берутся из ТЗ v0.3, не из демонстрационных 12/12/12 веб-макета.
- Телефонные проверки и калибровка вынесены в release gate TASK-022; production speed thresholds пусты.
- Оплата исчезает через 12 активных секунд по новым указаниям макета.
- Закреплённая зона пока фиксированный UTC-offset; IANA/DST — NAT-003.
- Ни Linux/headless, ни это ревью не заменяют Android/художественную приёмку. Final gate остаётся закрытым.
