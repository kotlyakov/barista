Godot 4.5.1.stable.official.f62fdbde1, OpenJDK 17.0.20, command-line tools 22.0, Android SDK 35/build-tools 35.0.0, platform-tools 37.0.1. Официальные шаблоны Godot той же версии, без Gradle.

Первый реальный экспорт обнаружил две недостающие настройки: include_filter у Android preset и import_etc2_astc. Исправлен preset и включён мобильный импорт текстур (требуется проверкой Android platform даже для технической сцены). Причина проверена по исходнику Godot 4.5.1 platform/android/export/export_plugin.cpp, has_valid_project_configuration. После исправления APK реально экспортирован и проверен. Ключ debug-подписи хранится вне Git; релизного ключа нет.

## Лицензия и ограничение проверки Android

Артур явно разрешил принять Android SDK соглашение сообщением «Принимаю». В установщике принято android-sdk-license, SDK установлен; повторно запрашивать то же согласие не нужно.

Дополнительно создан x86_64 preset `Android Emulator` с отдельным пакетом `org.kotlyakov.barista.emulator`. Эмулятор AOSP Android 35 / emulator 37.2.12 запускался без окна и без KVM, software TCG, SwiftShader. /dev/kvm отсутствует. Отдельная попытка smoke остановлена по таймауту 180 секунд: Android не завершил загрузку, в логе зависшие QEMU CPU threads. Установка APK/запуск внутри Android **NOT_RUN**. Это ограничение среды, а не доказанный дефект приложения. Проверки на реальном Pixel/другом телефоне не выполнялись.

## Короткая проверка на устройстве

Установить ARM64 APK. Проверить начало смены после выбора одного усиления, три прибора, переходы/перетап, стакан/drop мимо и гостю, монеты, паузу/сворачивание, закрытие и повторный запуск. Сообщить о вылете/пустом экране и версии Android. Финальная калибровка скоростного комбо: отдельно TASK-022/issue #25; боевые пороги пока пусты.

Для обновлений этой тестовой установки нужно сохранять ту же debug-подпись. Keystore сохранён отдельно в приватной Library: `libfile_76674d45c1b8819198ccdc529424af21`; не загружать его в Git и не выдавать за релизный ключ. Перед следующей сборкой в новой среде восстановить этот ключ в локальный debug keystore path. Генерация нового ключа вызовет несовместимость подписи при обновлении установленного APK.
