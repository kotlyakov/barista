## Учёт ресурсов
Для каждого файла: asset_id, версия, автор/генератор, источник, лицензия/права,
назначение, технические параметры, approval_id. Никаких случайных файлов из чужих игр.
Размеры/экспорт определяются после выбора стиля и экрана; сохранять исходники и экспорт раздельно.
Звук: ограничить одновременные голоса, не запускать длинную петлю заново на каждом тапе;
подготовить бесшовные петли, согласовать громкость, протестировать на динамике телефона.
