# TASK-042: межсменные покупки и развитие

Основание: GAME_SPEC0.4.2, ROGUELIKE_SPEC, интеграционный план035; выполнение уже поручено владельцем. Godot4.5.1, без новых зависимостей. Отдельный явный enable_development в Service v2; v1/UI/APK не переключаются.

## Контракт и порядок
1. `career.gd`: каталог с русскими описаниями/ценой/сроком, детерминированные3 предложения, состояние выбора, модули/цели/угощения/лиги. `career_economy_test.gd`: FAIL→PASS покупки/пропуск/уровни/лимиты/нулевой кошелёк.
2. Service: `buy_perk(id,day)`, `skip_perk(day)`, `buy_equipment(id,level)`, `buy_module(id)`, `equip_module(id,slot)`, `remove_module(slot)`, `reserve_gift(profile)`, `claim_goal(profile,tier)`, `promote_league(level)`. Действия только PREPARING, start_shift списывает обслуживание атомарно, отказ без изменения состояния. Эффекты вычисляются из сохранённого выбора и оборудования; не суммируются загрузкой. `career_effects_test.gd`: тепло/монеты/поток/критик/подарок/цель/известность/сто дней/малый и большой шаг.
3. Schema/Repository: строгая проверка внешнего economy, целей/предложений/активной смены/платежей; whitelist типизированных команд и откат. `career_economy_storage_test.gd`: отказ записи каждой покупки/подарка/цели/старта; reload и отдельные процессы.
4. Полный доменный прогон, независимое ревью всей задачи, один проход исправлений с регрессиями, полный GitHub CI с artwork. Зафиксировать отчёт/контекст/следующий044.

## Ограничения и развилки
Предпочтён один модуль каталога и расширение существующего Service/Schema; отдельный движок эффектов и новый магазин UI не нужны. Пробные числа в отдельном balance-документе не выдаются за утверждение владельца. Q/J/C/L/P,10 перетапов,5 мест и300с неизменны. Сохранённые tuning/grace не приобретают выдуманных эффектов: активация/предложение компенсации остаются044.

## Review Focus
- Устаревший день/двойной тап и повтор загрузки: нет второго списания/награды.
- Недостаток денег после включения drive: отказ старта, бесплатное снятие и запуск без долга.
- Подарок ушедшему/плохому гостю и критик: нет бесплатных денег или автоматического роста доверия.
- Внешний снимок с неверными эффектами/целью/составом модулей: отклонение до restore.
- Сочетание потоков на дне100/крайние сроки платежей/загрузка на закрытии: конечность,5 мест, тот же результат по кадрам.
