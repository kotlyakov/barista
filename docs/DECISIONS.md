## Договор об изменениях
Новое решение: ID, дата/зона времени, исходное сообщение, решение дословно либо точный пересказ,
альтернативы, причина, затронутые R-ID/TASK-ID, автор записи, кто утвердил.
Если решение заменено, пометить SUPERSEDED и сослаться на новое. Отказ сохранять как REJECTED.
Точное число из BALANCE_DRAFT не требует выдавать за волю владельца: зафиксировать калибровку и результаты.

## Машиночитаемые gates
state/DECISIONS.json — канонический текущий статус решений; эта таблица объясняет их содержание.
Допустимые статусы: OPEN, PROPOSED, ACCEPTED, REJECTED, SUPERSEDED.
Gate D-ID открыт только при ACCEPTED, непустом решении, accepted_by=Артур и source_message.
Координатор синхронно обновляет JSON и описание; при расхождении остановить только зависимую работу.
Повторная редакция не удаляет прошлое решение: новую запись со ссылкой supersedes и новый уникальный ID.
Задача фиксирует decision_records с ID принятого решения в момент исполнения.
