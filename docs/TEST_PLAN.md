# План проверок и доказательства готовности

| Проверка | Действие | Ожидаемое |
|---|---|---|
| Порог | N-1, N, N+1 тапов | На N готово; после допустимого запаса качество снижается |
| Монотонность | Много лишних тапов | q не растёт, не уходит ниже 0; прогресс/цвет не переполняются |
| Порядок | Тап следующего прибора до готовности | Этап и качество не меняются |
| Переход | После N тапнуть следующий | Переключение и первый засчитанный тап |
| Старый прибор | Тап прошлого после перехода | Нет изменения завершённого этапа |
| Ввод | Touch+mouse, удержание, два пальца, частые тапы | Один физический тап не считается дважды |
| Drop | Мимо/нужному/другому клиенту | Возврат либо одна выдача корректному клиенту |
| Оплата | Повторить выдачу и сбор | Нет второго платежа/начисления |
| Перезапуск | Закрыть на каждом этапе и после выдачи до сбора | Восстановление без потерь и дублирования |
| Сохранение | Оборвать запись/испортить основной файл | Последняя валидная копия либо понятная ошибка; без тихого обнуления |
| Чаевые | Плохой, серия хороших, постоянный клиент | Плохой без чаевых, серия и отношения независимы |
| Комбо | Ровно порог, чуть медленнее, q<1 | Бонус по утверждённому правилу, только один раз |
| Часы | Пауза/фон/08:00/перевод часов/пропуск дней | Нет ускоренного бонуса или повторных наград |
| Магазин | Двойной тап, мало денег, максимальный уровень | Покупка атомарна; баланс не отрицательный |
| RNG | Одинаковый seed и данные | Воспроизводимый поток для тестов |
| Отношения | Худшее значение и длинная серия плохих заказов | Герой не исчезает навсегда, вес корректен |
| Звук | 20 быстрых тапов, mute, фон | Нет клиппинга/неограниченных голосов, настройки сохраняются |
| Экран | Разные пропорции, вырез, крупный текст | Приборы и клиент доступны, надписи помещаются |
| Производительность | Длительная смена на целевом телефоне | Нет роста памяти/зависаний; замеры FPS/frame time записаны |

## Уровни
Домен: операции, деньги, покупки, day_key, сохранения — автоматизируемые проверки реального риска.
Интеграция: полный заказ, смена, магазин и восстановление.
Ручные: удобство, художественное соответствие, звук, реакция пальца и анимации.

Все финальные материалы APPROVED и версии совпадают; известны источники/лицензии.

## Уточнения v0.3 — качество и память настроений
- Для трёх этапов Q=(q1+q2+q3)/3; для эспрессо учитываются два обязательных этапа. Каждый q отдельно влияет на Q.
- При одинаковом Q, но разных ошибках выводятся разные дефекты вкуса; хорошее среднее не стирает перегретое молоко.
- Много ошибок разных этапов накапливаются в профиле дефектов; идеальный напиток требует всех этапов q=1.
- Сохранить mood/last_reaction/relationship/visits двух героев с разными значениями, перезапустить и проверить точное восстановление каждого.
- Перезапуск после выдачи/ухода не применяет эмоцию или отношение повторно; новый день сам по себе не обнуляет mood.
