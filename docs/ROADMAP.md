# План разработки и переходы
Этапы следуют исходному плану. Независимые задачи допускаются параллельно при непересекающихся файлах.

| Этап | Задачи | Выход и условие перехода |
|---|---|---|
| 1. ТЗ и подготовка | 001–004 | ТЗ одобрено, стек зафиксирован, воспроизводимый запуск, GitHub настроен |
| 2. Механика приготовления | 005–006 | Три прибора, полосы и порча работают на заглушках |
| 3. Обслуживание | 007–008 | Заказ → стакан → клиент → деньги; сохранение исключает повторы |
| 4. Качество и комбо | 009 | Скорость/серия/чаевые проверены и откалиброваны |
| 5. Герои | 010–011 | Герои представлены владельцу, отношения работают на ID |
| 6. Смена и экономика | 012 | Правила D02 реализованы, граница суток и восстановление проверены |
| 7. Магазин | 013 | Покупки и эффекты проверены, экономика играбельна |
| 8. Рогалик | 014 | D03 решено, временный/постоянный прогресс разделён |
| 9. Оформление и обучение | 015–018 | Макеты, графика и звук утверждены, реализация соответствует |
| 10. Проверки на устройстве | 019–020 | Баланс, производительность и кандидат APK проверены |
| 11. Пробный выпуск | 021 | Замечания игроков разобраны; решение о публикации отдельно |

Контрольные сборки: после 006 — приборы; после 008 — полный заказ; после 013 — смена+магазин;
после 018 — оформление; после 020 — кандидат для теста.
В сборке на заглушках явно писать «Технический прототип; оформление не утверждено».
Не оценивать календарные сроки без подтверждения стека, среды и результатов прототипа.
